# Arcade Gettone

Sala giochi in una sola pagina web: 11 giochi originali con musica chiptune ed effetti sonori.

**Arcade:** Blocchi · Bolle · Arpione · Invasori · Serpe · Mangiapunti
**Carte:** Ultima Carta · Briscola · Scopa · Solitario · Texas Hold'em contro il banco

Si gioca da tastiera sul computer o con i tasti a schermo sul telefono. Si installa come app (icona sulla schermata Home) e funziona anche offline dopo la prima apertura.

## Installare sull'iPhone
1. Apri il sito in Safari.
2. Tocca Condividi, poi "Aggiungi alla schermata Home".

## File
- `index.html` — tutta la sala giochi
- `manifest.webmanifest`, `sw.js`, `icons/` — installazione come app e modalità offline
